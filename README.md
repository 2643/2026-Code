## Robot

  2643's 2026 Robot utilizes an MK4i swerve drivetrain, turret shooter, and LimeLight to fire fuel at rapid speed. We've demonstrated to be able to accurately shoot from any location on the field, and likely will be able to shoot while moving very soon.
  
  Current features include:
  * Swerve Drive
  * Turret Auto Aim
  * Shooting and feeding capabilites
  * Middle and outpost autonomous routines
